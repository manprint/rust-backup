# S3-compatible module

`s3` backs up one bucket (optionally below a prefix) from AWS S3, MinIO, or a
compatible endpoint. Objects are streamed with `GetObject`; restores use bounded
5 MiB multipart parts and never create a local staging object.

Required parameter: `bucket`. Optional parameters: `endpoint`, `region`,
`prefix`, `access_key`, `secret_key`, and `path_style` (normally true for
MinIO). Destination policy is explicit: `create_bucket=true` permits a missing
bucket and `overwrite=true` permits collisions.

The plan records keys, sizes, ETags, content types and user metadata. Bucket
policy is restored when source credentials can read it. ACLs, tags and storage
class restoration are documented prototype limits.
